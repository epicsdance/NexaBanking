NEXA BANKING SERVICES — ANDROID STARTER PROJECT

This is a demo UI starter project, not a finished banking product and not an installable APK.
It does not read SMS, OTPs, call history, contacts, or private phone data. It does not perform real transactions.

Build:
1. Install Android Studio on a computer.
2. Open the NexaBankingStarter folder.
3. Allow Gradle sync and install the Android SDK requested by Android Studio.
4. Use Build > Build Bundle(s) / APK(s) > Build APK(s).

Before offering to customers:
- Use your own brand identity; do not imply RBI/government affiliation unless formally authorised.
- Connect only to a bank/BC/service provider with written authorisation and approved APIs.
- Add a secure backend, privacy policy, consent flows, authentication, audit logging, and security review.
- Never collect customer PINs, passwords, card data, or OTPs in this demo.
